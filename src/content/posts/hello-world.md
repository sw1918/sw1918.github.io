This is a sample post. To write a new one, add a Markdown file to `src/content/posts/` with the same frontmatter at the top, then push. The blog index, tag pages, home page, and RSS feed all update on their own.

Set `draft: true` in the frontmatter to keep a post visible locally but out of the published site.

## Formatting

Regular Markdown works: **bold**, *italics*, [links](/research), lists, and code:
